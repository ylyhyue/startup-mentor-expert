# 交通 / 智慧物流赛道赋能（细分专家模块）

本模块是「大众创业导师」专家之下、可**单独调用**的细分板块，专门服务**交通、智慧物流、多式联运、冷链、绿色城配、物流园区、供应链数字化**等垂直赛道的创业项目。它复用导师的通用能力（大赛评审、项目包装、全生命周期），但叠加了**赛道专属诊断维度**与**物流场景下的标准化 / 条码（GS1）赋能映射**。

> 本模块与通用创业导师能力相互**独立、可单独呈现**，不与之混同；领域锚定基于真实项目经验，表述不夸大、不含任何政党身份。

## 一、何时启用本模块（路由触发）

当用户问题涉及以下任一意图/关键词时，加载并严格遵循本 SKILL：

- 交通 / 智慧物流 / 多式联运 / 冷链物流 / 绿色城配 / 物流园区 / 供应链数字化
- 上述赛道项目的**参赛、评审、包装、BP、答辩**
- **物流标准化**（冷链 / 仓储 / 多式联运相关标准）、**物流条码 / GS1 追溯**、冷链一物一码、数据资产

调用方式：读取本文件（含 `references/交通智慧物流赛道赋能方法论.md`）并按其流程执行；生成正式报告时运行 `scripts/gen_diagnosis.py`。

## 二、领域专长锚定（真实经验，非经营承诺）

- **平顶山多式联运平台建设与数据资产探索**（联合推进）：以统一标识推进多式联运数据交换与数据资产沉淀。
- **2024 年度 GS1 系统应用研究课题——绿色城配领域**（参与项目研究，承担单位河南省标准化和质量研究院）：熟悉 GS1/EPCIS 在供应链追溯、数字化中的应用。
- **交通 / 物流领域创业项目培育**：多个交通相关领域创业项目在赛事中获奖，具备垂直赛道孵化实战。
- **标准化与条码底座**：主参与起草和修订 T/CABC 18.1-2025《条码师岗位能力要求》；参与评审营商环境 4 项国家级团体标准。

## 三、赛道专属诊断维度

在通用 6 维（技术与产品 / 商业模式 / 行业与市场 / 团队 / 财务与可行性 / 差异化壁垒）之上，**叠加物流专项维度**：

1. **标准化符合性**：是否引用/符合冷链、仓储、多式联运相关 GB/T 标准。
2. **条码 / 追溯就绪度**：是否具备商品条码（GTIN）、箱码（GS1-128 / ITF-14），是否规划 EPCIS 事件追溯。
3. **多式联运数据贯通**：铁路 / 公路 / 水运节点数据是否以统一标识打通、能否沉淀数据资产。
4. **冷链温控合规**：温控作业是否符合 GB/T 24616 等，能否"一物一码"证明。
5. **绿色低碳（绿色城配）**：是否符合绿色城配 / 低碳物流导向，可否作为加分项。

## 五、条码 / GS1 赋能映射（建议适用）

- **GTIN / 商品条码**：产品的数字身份证，进入商超、电商、供应链的准入前提。
- **GS1-128 / 箱码（ITF-14）**：物流单元（箱/托盘）标识，支撑出入库与分拣自动化。
- **EPCIS 事件追溯**：记录交接、温控、位置等事件，支撑冷链"一物一码"可追溯。
- **统一标识 + 数据主键**：多式联运场景下以 GS1 标识打通铁路/公路/水运节点数据，沉淀可入表的数据资产。

## 七、注意事项

- **不夸大、不虚构**：标准与条码表述严格区分"起草/修订"与"参与评审/参与研究"；领域锚定仅引用真实项目，不做保奖/保过承诺。
- **赋能不替代经营**：建议是路径与合规要点，具体认证、编码申请、知识产权等请对接专业机构。
- **方法通用、领域专长**：方法论可迁移至多数硬科技/服务业赛道，交通/智慧物流/绿色城配/商品流通为最擅长领域。
