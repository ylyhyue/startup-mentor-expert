# 交通 / 智慧物流赛道赋能方法论（细分板块参考）

> 本文件为 `transport-logistics-track` 技能模块的详细方法论参考，配合 SKILL.md 使用。

## A. 赛道理解框架

交通 / 智慧物流赛道的创业项目通常落在以下子领域之一：

- **多式联运与枢纽经济**：公铁水空联运、物流枢纽、多式联运数据平台。
- **冷链物流**：冷链仓储、冷链运输、生鲜/医药冷链、温控追溯。
- **绿色城配**：新能源配送、城市共同配送、低碳物流。
- **智慧物流园区 / 仓储**：自动化仓储、智慧园区、仓单数字化。
- **供应链数字化与追溯**：一物一码、全链路追溯、数据资产。

## B. 通用 6 维评审 + 物流专项叠加（评分口径）

| 维度 | 评委关注点 | 物流专项观察点 |
|---|---|---|
| 技术与产品 | 技术壁垒、成熟度 | 是否符合冷链/仓储标准、追溯技术真实性 |
| 商业模式 | 盈利模型、天花板 | 数据资产能否变现、平台双边网络 |
| 行业与市场 | 市场规模、竞争格局 | 多式联运/绿色城配政策红利 |
| 团队 | 互补性、执行力 | 是否具备标准化/编码专业资源 |
| 财务与可行性 | 测算合理性 | 重资产回报周期、补贴依赖度 |
| 差异化壁垒 | 护城河 | 标准化话语权 + 条码/GS1 追溯合规 |
| 标准化符合性（专项） | — | 已引用/计划引用哪些 GB/T |
| 条码/追溯就绪度（专项） | — | GTIN、箱码、EPCIS 规划 |
| 多式联运数据贯通（专项） | — | 节点数据是否统一标识打通 |
| 冷链温控合规（专项） | — | 温控作业标准符合性、一物一码证明 |
| 绿色低碳（专项） | — | 绿色城配/低碳导向加分 |

## C. 标准化赋能路径（按企业阶段）

1. **创意/立项**：标准符合性预判（查新本企业产品/服务对应的 GB/T）。
2. **产品开发**：引用相关产品/冷链标准，把"经验"写进"参数"。
3. **试产/上市**：创建"标准化良好行为"，用标准为企业背书、增信。
4. **成长/融资**：牵头/参与团标或地标研制，获得行业话语权。
5. **规模化**：输出企业标准、参与更高层级标准，复制扩张。

## D. 条码 / GS1 赋能路径（按企业阶段）

1. **创意/立项**：编码规划（是否需厂商识别代码、哪些产品需 GTIN）。
2. **产品开发**：申请商品条码，规划一物一码与箱码。
3. **试产/上市**：条码印刷质量合规，部署追溯码（EPCIS 事件）。
4. **成长/融资**：构建全链路 GS1 追溯体系，沉淀数据资产。
5. **规模化**：数字化追溯复制，多式联运数据以统一标识贯通。

## E. 真实项目锚定（用于背书话术，非承诺）

- 平顶山多式联运平台建设与数据资产探索（联合推进）。
- GS1 绿色城配课题（参与项目研究）。
- 交通/物流领域创业项目培育与参赛获奖经验。
- T/CABC 18.1-2025 主参与起草和修订；营商 4 标准参与评审。
