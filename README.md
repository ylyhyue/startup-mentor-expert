# 大众创业导师（标准化与条码赋能）· WorkBuddy 专家

一个独立发布的 WorkBuddy 专家（Agent），由 **岳永强** 打造。它把"创业导师 + 标准化专家 + 商品条码（GS1）专家"三重身份合为一体，是区别于普通创业导师的**特色赋能型**顾问。

> 一句话：以评委视角体检项目、以投资人语言包装项目，并以**标准化体系**与**商品条码/GS1** 为特色杠杆，为初创企业提供贯穿全生命周期的指导与赋能。

---

## 为什么不一样（特色）

普通创业导师大多停留在"BP 包装 + 路演辅导"。本专家额外带来两套**可落地的硬核赋能工具**，这正是岳永强的核心知识产权与履历底座：

- **标准化赋能**：帮企业识别"该立哪些标准、如何参与团标/地标研制"以提升质量信用与行业话语权；设计标准化体系框架（参考 GB/T 24421 等）；指导"标准化良好行为"创建，用标准为企业背书、增信、对接政策。
- **条码 / GS1 赋能**：商品条码是产品进入商超、电商、供应链的"数字身份证"；GS1/EPCIS 可追溯方案支撑食品、农产品、冷链、医药等赛道的"一物一码"追溯与数据资产沉淀。

两者由以下公开履历支撑（表述不含任何政党身份，不夸大、不虚构）：

- **主参与起草和修订**团体标准 T/CABC 18.1-2025《条码师岗位能力要求》——商品条码人才领域的核心标准。
- 参与 2024 年度 GS1 系统应用研究课题（绿色城配领域，承担单位河南省标准化和质量研究院）。
- 参与评审营商环境领域 4 项国家级团体标准。

## 核心能力（六大模块）

1. **大赛评审视角体检**：技术与产品 / 商业模式 / 市场 / 团队 / 财务等维度结构化打分，输出短板清单。
2. **项目包装与路演辅导**：BP、路演 PPT、答辩稿；高频追问与 Q&A 话术。
3. **标准化赋能（特色）**：标准体系搭建、团标/地标研制参与、良好行为创建。
4. **条码 / GS1 赋能（特色）**：商品编码合规、一物一码追溯防伪、供应链数字化与数据资产。
5. **垂直领域孵化**：交通 / 智慧物流 / 绿色城配行业洞察与资源对接。
6. **企业全生命周期指导与赋能（主线）**：评审体检 → 项目包装 → 标准筑基 → 条码准入 → 市场拓展 → 融资成长，一条贯穿式赋能链。

### 企业全生命周期赋能地图（特色交付物）

| 阶段 | 标准化动作 | 条码 / GS1 动作 | 创业辅导动作 |
|---|---|---|---|
| 创意 / 立项 | 查新与标准符合性预判 | 编码规划 | 赛道与组别定位、BP 雏形 |
| 产品开发 | 参与 / 引用相关产品标准 | 商品条码申请、一物一码规划 | 技术壁垒与差异化定位 |
| 试产 / 上市 | 标准化良好行为创建 | 条码印刷质量合规、追溯码部署 | 路演包装、首批客户拓展 |
| 成长 / 融资 | 牵头 / 参与团标研制 | GS1 追溯体系、数据资产入表 | 商业模式打磨、融资节奏 |
| 规模化 | 输出企业标准 / 参与地标 | 全链路数字化追溯 | 组织、合规、复制扩张 |

## 使用示例（直接复制到对话）

- 帮我评估这个参赛项目，指出短板，并结合标准化与条码（GS1）给出企业全生命周期赋能建议
- 把我的技术/项目包装成能打动评委的商业计划书（BP）大纲，并告诉我该采用哪些标准和条码
- 针对初创企业，给出全生命周期赋能路线图，按阶段列出标准化动作、条码（GS1）动作与创业辅导动作

## 安装（作为 WorkBuddy 专家市场导入）

本仓库本身就是一个**单专家市场**，目录结构如下：

```
startup-mentor-expert/
├── .codebuddy-plugin/
│   └── marketplace.json        # 市场清单（指向下方插件）
├── plugins/
│   └── startup-mentor/         # 专家本体
│       ├── .codebuddy-plugin/plugin.json
│       ├── agents/startup-mentor.md
│       ├── README.md
│       └── avatars/expert.png
├── README.md
└── LICENSE
```

在 WorkBuddy 中：将本仓库作为"专家市场"添加，即可看到并 `@大众创业导师` 调用。
